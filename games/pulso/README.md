# Pulso

Juego cooperativo de ritmo para 1–8 jugadores o modo «Cualquiera». Cuatro zonas de color reciben notas simples, acordes simultáneos y notas largas mientras el grupo mantiene una reserva común de energía.

Id del juego: `pulso`.

## Mecánica

- La pista y sus tiempos son deterministas para facilitar pruebas y sincronización.
- La dificultad modifica el tempo, la ventana de acierto y el coste de cada fallo.
- Los aciertos aumentan el combo y la energía; los fallos rompen el combo y consumen energía.
- Llegar al final de la pista gana la partida. Llegar a cero de energía o agotar el tiempo la pierde.
